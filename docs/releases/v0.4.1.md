# GAFIME v0.4.1 Release Notes

GAFIME v0.4.1 is a math-correction release for mutual-information scoring and
discrete candidate ranking. It keeps the v0.4.0 public API stable while making
the default selector more reliable across small and large datasets.

## What changed

- `EngineConfig.mi_bins` now defaults to `96` and is treated as an adaptive
  maximum, not a fixed histogram size.
- General `mutual_info` report metrics now use adaptive dense quantile bins
  with finite-sample bias correction.
- Discrete split-aware ranking now uses soft-binary MI:
  candidate membership is scored as weighted inside/outside membership against
  adaptive target bins.
- Discrete selector scoring now guards tiny-support masks with effective
  sample-size checks before assigning MI or variance-reduction gain. The support
  floor is adaptive, so true narrow regions in small datasets are not
  over-pruned.
- CUDA native discrete selection has a new adaptive entrypoint:
  `gafime_discrete_selection_adaptive_cuda`.
- Rust batching now groups discrete selector candidates into homogeneous MI
  template batches before CUDA dispatch.
- Rust helper crate/module version metadata is aligned to `0.4.1`, and source
  distributions exclude local native build artifacts.
- Validation now includes sklearn-backed ranking checks, exact contingency-table
  MI checks, and CUDA parity across every MI template capacity.
- v0.4.1 validation also checks variance reduction against sklearn tree-stump
  behavior, R2-style metrics against sklearn linear regression, and selector
  ordering against Ridge/GBM cross-validation gains on powered cases.
- Older CUDA libraries without the adaptive selector symbol fall back to the
  corrected Python selector instead of using the older sparse 16x16 selector.

## Compatibility

- Existing `GafimeEngine`, `EngineConfig`, `ComputeBudget`, and
  `DiscreteFunctionCandidate` usage remains valid.
- `metric_names` still controls public report metrics.
- `discrete_ranking="split_aware"` still returns the same selector-score keys:
  `mutual_info`, `variance_reduction`, `residual_abs_corr`, and
  `residual_r2_gain`.
- `discrete_ranking="metric"` still ranks by the selected public report
  metrics.
- GPU hard discrete mode is still unsupported; use `discrete_mode="soft"` on
  CUDA/Metal and CPU/NumPy for hard mode.

## Validation

The release validation path is:

```bash
PYO3_PYTHON=/path/to/python3.12 python setup.py build_ext --inplace
python -m pytest tests/test_discrete_selection_scores.py tests/test_discrete_functions.py tests/test_discrete_native_gpu.py -q
python -m pytest -q
cargo test --manifest-path src/cpu/gafime_cpu/Cargo.toml
git diff --check
python -m build
```

Before publishing, install the locally built wheel in a clean environment and
smoke-test import, backend resolution, CUDA discrete selector availability, and
an end-to-end discrete-engine run. Do not validate v0.4.1 with a previously
published wheel.
