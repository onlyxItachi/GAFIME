# GAFIME v0.4.6 Draft Notes

This draft tracks local work before release approval. Do not publish without
explicit maintainer sign-off.

## Native Report Access

- `DiagnosticReport` now stores result rows in a native report table when the
  C++ Core extension is available.
- Normal framework integration should use report properties:
  `report.interactions`, `report.stability`, `report.permutations`,
  `report.decision`, `report.backend`, and `report.warnings`.
- `DiagnosticReport.to_dict()` is deprecated. It still works for legacy export
  code, but emits `DeprecationWarning` and materializes a JSON-style copy only
  at the boundary.
- Internal tests and Metal benchmark workflows no longer use `report.to_dict()`
  as a runtime data-flow check.

## Platform-Aware Backend Policy

- `backend="auto"` is platform-aware:
  - macOS: `metal` then `core`
  - Linux/Windows x86_64: `cuda` then `core`
  - Linux/Windows ARM64: `core`
- Explicit impossible backend requests now fail clearly:
  - `backend="cuda"` on macOS is invalid.
  - `backend="metal"` outside macOS is invalid.
  - current ARM Linux/Windows wheels do not expose CUDA.
- `backend="gpu"` is deprecated because it is ambiguous across platforms. Use
  `auto`, `cuda`, `metal`, or `core`.
