# GAFIME v0.4.1 Edge Validation Log

This log records the iterative math hardening done for v0.4.1 discrete
selector ranking. The goal was to find ranking failures caused by estimator or
kernel math, fix real issues, and separate those from statistically
underpowered cases.

## Iteration 1: Independent Estimator Comparison

Added hardened regression coverage in `tests/test_discrete_selection_scores.py`:

- exact soft-binary MI check against a manual corrected binary contingency
  table,
- multi-seed planted threshold + rectangle ranking compared with
  `sklearn.feature_selection.mutual_info_regression`,
- pure-noise false-positive floor checks,
- monotonic signal-strength checks against sklearn MI.

Result:

```text
tests/test_discrete_selection_scores.py: 12 passed
full pytest: 28 passed, 4 skipped
```

## Iteration 2: Small-Sample Stress Sweep

Ran a stress sweep across:

- sample sizes: `96`, `192`, `512`, `5000`, `20000`,
- target types: binary, ternary, continuous, heavy-tailed,
- standard threshold + rectangle signals,
- rare threshold signals,
- monotone target transforms.

Initial result:

```text
records: 115
failures: 13
```

Diagnosis:

- Failures concentrated at `n=96`.
- The true rectangle often had only `3-6` hard samples.
- The fixed `n_eff >= 8` support guard zeroed or strongly suppressed true
  narrow regions before ranking.
- This was a real math-policy bug: a constant medium-data support floor was too
  aggressive for small datasets.

Change made:

- Added `adaptive_min_effective_support(n_samples)`.
- New support floor:

```text
min_support = min(8.0, max(3.0, 0.02 * n_samples))
```

- Python soft-binary MI and variance-reduction scoring now use this floor.
- CUDA adaptive selector kernel mirrors the same formula.
- Added regression coverage for small-dataset support behavior.

Validation:

```text
tests/test_discrete_selection_scores.py: 14 passed
```

## Iteration 4: Powered Stress Sweep

Re-ran the stress sweep with explicit statistical guardrails:

- strict top-rank checks for powered cases,
- diagnostic-only classification for `n=96` rectangles with fewer than eight
  true samples,
- monotone target-transform invariance checks.

Result:

```text
powered_cases: 256
underpowered_diagnostics: 24
failures: 0
```

Underpowered diagnostic examples:

```text
n=96, true rectangle hard support = 3-6 samples
```

These are not treated as estimator failures because sklearn MI also commonly
misses the second planted candidate in this regime. The selector still ranks
the strong threshold signal correctly; the rectangle is below the amount of
evidence needed for reliable one-shot ranking.

## Iteration 5: Industry-Standard Metric Equivalence

Added independent validation for the non-MI selector/report components:

- `variance_reduction` is checked against manual hard-split SSE reduction and
  `sklearn.tree.DecisionTreeRegressor(max_depth=1).score(...)` on the same
  binary mask.
- `residual_r2_gain` is checked against
  `sklearn.linear_model.LinearRegression().score(candidate_feature, residual)`.
- Public report `r2` is checked against sklearn univariate linear regression
  R2 on the exact generated feature.
- Composite selector ranking is compared with train-only
  `cross_val_score(Ridge(...), scoring="r2")` on powered planted candidates.
- Composite selector ranking is also compared with train-only
  `cross_val_score(HistGradientBoostingRegressor(...), scoring="r2")`.

Result:

```text
tests/test_discrete_selection_scores.py: 19 passed
```

Interpretation:

- We can claim ranking agreement for powered validation cases against sklearn
  MI, Ridge CV gain, and GBM CV gain.
- We can claim exact equivalence for hard-mask variance reduction against
  manual SSE/sklearn stump behavior.
- We can claim exact equivalence for R2-style metrics against sklearn linear
  regression on the same generated feature.
- We do not claim sklearn-score equality for MI, because sklearn uses a
  different kNN-style MI estimator. The hardened guarantee is ranking agreement
  and exact sanity checks for the binary MI case.

## Release Note Summary

- Fixed a small-sample ranking edge case by replacing the fixed effective
  support floor with an adaptive floor.
- Mirrored the support-floor rule in the CUDA adaptive selector kernel.
- Added sklearn-backed ranking validation and exact contingency-table checks.
- Added sklearn/manual equivalence checks for variance reduction, residual R2,
  public R2, Ridge CV gain ranking, and GBM CV gain ranking.
- Added CUDA parity checks across every MI template capacity.
- Aligned Rust helper version metadata and hardened sdists against local native
  binary leakage.
- Remaining observed misses are statistically underpowered region cases with
  fewer than eight true samples, not a kernel or estimator mismatch.
